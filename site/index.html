          How it works

          The five steps behind Earn coins, from the sign-in to the new balance. They are marked while you complete a demo offer.

          1. 1
            Game page

            Age check and guest sign-in

            The first time, the player confirms they are 16 or older and gets a guest sign-in.

          2. 2
            Your server

            The link is signed

            The server signs the offerwall link for that player with the link hash salt.

          3. 3
            Moonetix offerwall

            The player completes an offer

            The offerwall opens over the game. The player completes an offer.

          4. 4
            Your server

            Signed postback, credited once

            Moonetix sends a signed postback. The server checks the hash and credits each transaction once.

          5. 5
            Game page

            The game reads the balance

            The game reads the new balance. It never adds coins itself.

          In demo mode a script on this page stands in for the server, with fake keys. On your site the salt and the postback key stay on the server.

          What the example shows

          Three things for a web game with a coin balance. The game earns when a player completes an offer, and the player gets your own currency for it.

          Add an Earn coins button
          Open the Moonetix offerwall in a pop-up over your web game with one script tag and one Moonetix.open call, so players stay on the page.
          Credit coins from postbacks
          Copy the server: it checks each signed postback, credits a transaction once and takes back exactly that amount on a reversal.
          Keep the keys off the client
          The server signs the offerwall link for the signed-in player. The game only reads the balance and never adds coins itself.

          Use it in your project

          Clone the example, put in your keys and swap in your own game: the server is plain Node.js with no npm packages.

          Node.js 22.13 or later. The example starts with the test keys from .env.example, and real offers need an approved Moonetix app.

          Terminal
          git clone https://github.com/moonetix/offerwall-html5-game.git
cd offerwall-html5-game
cp .env.example .env
npm start

          Put your App ID, link hash salt and postback secret key in .env, then save this postback URL on the Postback page of your dashboard:

          Postback URL
          https://YOUR_HOST/moonetix/postback?user={user_id}&tx={transaction_id}&event={event_id}&status={status}&reward={reward}&payout={payout}&offer={offer_name}&hash={hash}

          The game runs on http://localhost:3000. The README has the settings table and a checklist for a real test postback.

          The two calls your server makes: sign the offerwall link for a player, and handle the postback. Save this in the repo folder and run it with node try.js. It uses the test keys and an in-memory database.

          try.js
          const { buildWallLink, postbackHash } = require('./src/moonetix');
const { handlePostback } = require('./src/postback');
const { openStore } = require('./src/store');

const store = openStore(':memory:');
const user = String(store.createPlayer().id);

console.log(buildWallLink({ appId: 'demoapp0000000000000001', linkSalt: 'test_link_salt_not_secret', userId: user }));

const postbackKey = 'test_postback_key_not_secret';
const params = new URLSearchParams({ tx: 'tx_1001', user, reward: '150', status: '1' });
params.set('hash', postbackHash(postbackKey, 'tx_1001', user, '150', '1'));

console.log(handlePostback(params, { postbackKey, store }));
console.log(handlePostback(params, { postbackKey, store }));

          The second call is the same postback again: the transaction is already stored, so nothing is credited twice. A wrong hash gets 403 invalid hash before anything else runs.

          One script tag and one call. The page asks its own server for the signed link, checks where it points and opens the pop-up.

          HTML
          <script src="https://wall.moonetix.com/embed.js" async></script>
          JavaScript
          const res = await fetch('/api/offerwall-link', { headers: { Authorization: `Bearer ${token}` } });
const { url } = await res.json();
if (url.startsWith('https://wall.moonetix.com/')) Moonetix.open(url);

          token is the player's sign-in token. The pop-up loads only on https pages of the website registered for your app. On http://localhost the example opens the same link in a new tab instead.
